# video-tools

Инструмент для помощи в монтаже. Пока один режим: **размытый фон** —
переформатирование видео под заданное соотношение, пустые области
заполняются этим же видео (cover + размытие).

```bash
docker compose up --build
# http://localhost:8000
```

Несколько файлов на входе → результат приходит архивом `.zip`.
